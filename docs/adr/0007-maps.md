# ADR 0007: Maps

Status: Accepted

## Decision

The marketing demonstration uses **MapLibre GL JS** with **OpenFreeMap's dark style** when WebGL2 is available. If WebGL2 is unavailable or MapLibre cannot initialize, it uses an interactive **Leaflet** raster map. Live vehicle tracking and trip history use **MapLibre GL JS** with Geoapify's `osm-bright` style.

OpenFreeMap provides OpenStreetMap roads without a key, which keeps the labelled landing-page demo simple. The Leaflet fallback uses Geoapify raster tiles when a browser key is configured, and OpenStreetMap tiles otherwise. Geoapify provides the customer-facing basemap for live tracking and trip history, configured with a browser key restricted to the app's HTTP referrers.

## Consequences

- The marketing demo remains interactive without WebGL2. Live tracking and trip history still require WebGL2; the tracking page shows the vehicle list if Geoapify is unavailable.
- Geoapify requires a browser key restricted to the app's HTTP referrers.
- `NEXT_PUBLIC_MAP_STYLE_URL` can point at another provider. OpenFreeMap is a free community service with no service guarantee, so review it before relying on it in production.
- The public Geoapify key is not a secret. Restrict it by website referrer and configure usage limits in Geoapify.

## The landing page demonstration

- Vehicles, positions and statuses are invented, and labelled "DEMO · SIMULATED VEHICLE DATA". They aren't customers or connected devices.
- Routes are real road geometry from OpenStreetMap, generated once with the public OSRM service and stored in `demo-routes.ts`, so nothing depends on a routing service at runtime.
- The map and list only use the `FleetFeed` interface. A WebSocket feed can replace the simulator without changing them.
- The simulator runs at three times real speed so movement is visible at this zoom. The displayed speeds stay realistic.
