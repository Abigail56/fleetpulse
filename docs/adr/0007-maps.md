# ADR 0007: Maps

Status: Accepted

## Decision

Maps use **MapLibre GL JS** with **OpenFreeMap's dark style**, instead of the Leaflet named in the product specification.

Dark raster tiles from CARTO, the usual Leaflet choice, were tested first and returned "API key required" watermarks. OpenFreeMap provides OpenStreetMap roads with no key, and its terms allow commercial use. MapLibre also has built-in gestures that stop a map trapping page scrolling.

## Consequences

- MapLibre is much larger than Leaflet and needs WebGL. It's loaded separately so it doesn't slow the first page load, and if it can't run, a plain route view appears instead.
- Phase 11's live map should use MapLibre too, so the product has one map library.
- `NEXT_PUBLIC_MAP_STYLE_URL` can point at another provider. OpenFreeMap is a free community service with no service guarantee, so review it before relying on it in production.
- OpenStreetMap attribution must stay visible.

## The landing page demonstration

- Vehicles, positions and statuses are invented, and labelled "DEMO · SIMULATED VEHICLE DATA". They aren't customers or connected devices.
- Routes are real road geometry from OpenStreetMap, generated once with the public OSRM service and stored in `demo-routes.ts`, so nothing depends on a routing service at runtime.
- The map and list only use the `FleetFeed` interface. A WebSocket feed can replace the simulator without changing them.
- The simulator runs at three times real speed so movement is visible at this zoom. The displayed speeds stay realistic.
